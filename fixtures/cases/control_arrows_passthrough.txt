# Only Control (optionally with Shift) is remapped. Control+Option and
# Control+Command arrows, Shift+arrow, and plain arrows pass through untouched.
# Control+Shift+arrow is covered by control_shift_arrows.txt.
> key_down control_l control
< pass key_down control_l control
> key_down right control|option
< pass key_down right control|option
> key_up right control|option
< pass key_up right control|option
> key_down left control|shift|option
< pass key_down left control|shift|option
> key_up left control|shift|option
< pass key_up left control|shift|option
> key_down up control|command
< pass key_down up control|command
> key_up up control|command
< pass key_up up control|command
> key_up control_l -
< pass key_up control_l -
> key_down shift_l shift
< pass key_down shift_l shift
> key_down down shift
< pass key_down down shift
> key_up down shift
< pass key_up down shift
> key_up shift_l -
< pass key_up shift_l -
> key_down left -
< pass key_down left -
> key_up left -
< pass key_up left -
> key_down up caps
< pass key_down up caps
> key_up up caps
< pass key_up up caps
