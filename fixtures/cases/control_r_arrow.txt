# Right Control+arrow uses right Command for the burst and restores right Control.
> key_down control_r control
< pass key_down control_r control
> key_down right control
< suppress
< post key_up control_r -
< post key_down command_r command
< post key_down right command
< post key_up command_r -
< post key_down control_r control
> key_up right control
< suppress
< post key_up right command
> key_up control_r -
< pass key_up control_r -
