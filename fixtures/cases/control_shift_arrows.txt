# Control+Shift+arrow (physical Command+Shift+arrow) reaches apps as
# Command+Shift+arrow: select to line start/end, document top/bottom. Same
# burst as Control+arrow with Shift carried on every posted event; the Shift
# key itself passes untouched. All four arrows, autorepeat, and releasing
# Control before the arrow (arrow up keeps Shift, no stuck Control/Command).
